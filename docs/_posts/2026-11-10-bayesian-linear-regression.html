Bayesian linear regression is ordinary linear regression in which the weight vector w is treated as a random variable: it gets a prior distribution, and fitting the model means computing the posterior distribution of w given the data, rather than a single best estimate. The question this note answers is what that buys over ridge or lasso, which already look like "regression with a prior".

Ridge regression is the peak of the Bayesian posterior; Bayesian linear regression keeps the whole posterior. The posterior mean is exactly the ridge solution with λ = σ²/τ². The extra information is the posterior covariance, which turns into an error bar on every prediction and into a criterion for choosing λ from the training data alone.

The same model, read as probability

Start from the model that least squares already assumes implicitly. With features φ(x) (the raw inputs, or any fixed basis expansion of them), each target is a linear function plus Gaussian noise:

yn = wTφ(xn) + εn,   εn ~ N(0, σ²)

Maximising this likelihood is ordinary least squares. Now add a prior on the weights: each one is zero-mean Gaussian with variance τ². It is convenient to work with precisions (inverse variances): α = 1/τ² for the prior and β = 1/σ² for the noise. Bayes' rule gives the posterior up to a constant, and its negative log is

−ln p(w | y) = (β/2) Σn (yn − wTφn)² + (α/2) ‖w‖² + const

Multiply by 2/β and this is the ridge objective ‖y − Φw‖² + λ‖w‖² with

λ = α / β = σ² / τ²

So the ridge penalty is not an arbitrary knob: it is the ratio of the noise variance to the prior variance of the weights. Large λ means noisy data or a strong belief that weights are small. Swapping the Gaussian prior for a Laplace prior, p(wj) ∝ exp(−|wj|/b), turns the penalty into ‖w‖₁ and gives the lasso (with λ = σ²/b for the ½‖y − Φw‖² + λ‖w‖₁ convention).

Ridge and lasso are already Bayesian in their assumptions; they just stop at the peak. Everything else in this note comes from not stopping there.

Prior × likelihood, one weight at a time

The cleanest picture uses a single weight: a line through the origin, y = w·x + ε, with true slope 0.5. The posterior over w is the prior multiplied by the likelihood and renormalised. The ridge or lasso estimate is the location of the posterior's peak; the shaded region is the 95% credible interval, which no point estimate gives you.

Things to try:

  • Set n = 0: the posterior is the prior. Add points and the likelihood narrows and drags the posterior toward the data; with n = 50 the prior barely matters.
  • Shrink τ: the prior dominates and the estimate is pulled to 0 (that is the "shrinkage" in ridge). Raise σ: each point is less informative, so the same thing happens. Only the ratio σ²/τ² matters for the peak.
  • Switch to the Laplace prior and shrink τ (or use few points): the peak snaps to exactly 0, which is how lasso produces sparse solutions. The posterior mean, however, is not zero: the mass on either side of the kink still pulls it away. A fully Bayesian lasso averages instead of picking the peak, and so does not give exact zeros.

The posterior in closed form

With a Gaussian prior and Gaussian noise, the posterior is again Gaussian (the prior is conjugate), so it is fully described by a mean vector and a covariance matrix. With design matrix Φ (one row φ(xn)T per data point):

p(w | y) = N(w | mN, SN)
SN−1 = α I + β ΦTΦ
mN = β SN ΦTy = (ΦTΦ + (α/β) I)−1 ΦTy

The second form of mN is the ridge closed form, term for term. Three readings of the covariance are worth keeping:

  • Precisions add. The prior contributes αI. Each data point contributes βφnφnT, a rank-one increase in certainty along the direction φn and no information in the directions orthogonal to it.
  • SN does not depend on y. How uncertain the weights are depends only on where you measured (and on σ), not on the values you observed. This is also why Bayesian linear models are used for experimental design.
  • Learning is sequential. Today's posterior is tomorrow's prior: updating one point at a time, with N(mN, SN) as the prior for point N+1, gives exactly the same result as the batch formula.

The predictive distribution: where the error bars come from

For a new input x*, the Bayesian prediction averages the model's prediction over every plausible weight vector, weighted by the posterior. For this model the integral is again Gaussian:

p(y* | x*, data) = N( mNTφ(x*),  σN²(x*) )
σN²(x*) = σ² + φ(x*)T SN φ(x*)

The mean is the ridge prediction. The variance has two parts:

  • σ², the noise (aleatoric) term. Irreducible; it is the same everywhere and no amount of data removes it.
  • φ(x*)TSNφ(x*), the model (epistemic) term. The uncertainty about w, projected onto the features at x*. It shrinks as data arrives near x* and stays large where there is none. It never increases when a point is added.

Choosing λ without cross-validation: the evidence

With ridge, λ is chosen by cross-validation. The Bayesian setup offers a different route. Integrating the weights out gives the probability of the observed targets as a function of the hyperparameters alone, called the marginal likelihood or evidence:

p(y | α, β) = ∫ p(y | w, β) p(w | α) dw

For this model it has a closed form (M is the number of weights, N the number of points):

ln p(y | α, β) = (M/2) ln α + (N/2) ln β − E(mN) − ½ ln|SN−1| − (N/2) ln 2π
E(m) = (β/2) ‖y − Φm‖² + (α/2) ‖m‖²

E(mN) is the regularised fit, which favours flexible models. The log-determinant and ln α terms penalise how much the posterior had to shrink relative to the prior, which favours simple ones. The balance is a built-in Occam's razor: a model that could have explained many datasets spreads its probability thinly and is penalised for it, even if it fits this one well.

Maximising the evidence over α and β (called empirical Bayes, type-II maximum likelihood or the evidence approximation) has a simple fixed-point solution:

γ = M − α tr(SN),   α ← γ / ‖mN‖²,   σ² ← ‖y − ΦmN‖² / (N − γ)

γ lies between 0 and M and counts the effective number of parameters: weights that the data determines well, as opposed to ones held near zero by the prior. The noise update is the familiar residual variance with degrees of freedom N − γ. This uses only the training data; no held-out fold is needed.

The evidence is a statement about the model family as well as the data: if the model is badly misspecified, maximising it can still produce overconfident error bars, so it complements rather than replaces checking predictions on held-out data.

Extensions that follow directly from this setup:

  • Unknown noise. Treat σ² as random too, with an inverse-gamma prior (the Normal-inverse-gamma conjugate prior). The predictive distribution becomes a Student-t, with heavier tails when there is little data.
  • Non-Gaussian priors. A Laplace or horseshoe prior has no closed-form posterior; it needs MCMC or variational approximations. The Bayesian lasso (Park and Casella, 2008) is the Laplace case.
  • One α per weight. Giving each weight its own prior precision and maximising the evidence drives many αj to infinity, pruning those weights. This is automatic relevance determination, the basis of the relevance vector machine (Tipping, 2001).
  • Infinitely many basis functions. The predictive distribution depends on the features only through inner products φ(x)Tφ(x′). Replacing them with a kernel gives a Gaussian process. This also fixes a weakness visible with localised basis functions: far from every basis centre φ(x*) ≈ 0, so the model variance collapses back to a small value exactly where the model knows least.
